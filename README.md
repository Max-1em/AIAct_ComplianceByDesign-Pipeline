# AIAct_ComplianceByDesign-Pipeline

AIAct_ComplianceByDesign-Pipeline
Diese Pipeline generiert bei jedem Push automatisierte Compliance-Dokumente.

📦 Erstellte Artefakte

Die Pipeline erzeugt folgende Artefakte als Build-Output:

Technische Dokumentation: Strukturierte Berichte gemäß EU AI Act.

Risiko-Assessment: Dokumentation der Klassifizierung und Maßnahmen.

Model Card: Transparenz-Steckbrief mit folgendem Inhalt:

Model Name: Applicant Scoring Model

Purpose: AI supports HR screening.

Risk: Potential bias.
